Mỗi file có metadata ở đầu. Khi đưa vào CMS: `meta_title` → tiêu đề SEO; `meta_description` → mô tả SEO; H1 → tên bài; phần sau H1 → nội dung. Không chép YAML hoặc ghi chú nội bộ của README này vào nội dung công khai. Giữ trạng thái Draft cho đến khi anh duyệt. Tất cả hình ảnh minh hoạ đều dùng ảnh thực tế từ kho lưu trữ DMF và sơ đồ SVG chuẩn nhận diện thương hiệu.

Các bài đã có link đến trang dịch vụ và form đang hoạt động (`/services/skilled-workers`, `/services/azubi`, `/services/seasonal`, `/fuer-arbeitgeber/personalbedarf`, `/fuer-arbeitgeber/zeitplan`, `/roi-rechner`). Không cần đổi menu hoặc layout.
